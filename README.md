# Jood Kids Store V36

نسخة متجر إلكتروني فعلية مبنية فوق V35 مع الحفاظ على Firebase وCloudinary وهيكل البيانات الحالي.

## أهم ما تغير
- صفحة رئيسية ديناميكية مبنية من المنتجات الفعلية: الأقسام، أحدث الموديلات، والعروض.
- بطاقات منتجات تتجه إلى صفحة منتج مستقلة وقابلة للمشاركة.
- فلتر متجر فعلي للمواسم والتصنيفات والعروض.
- حالة توفر لكل موديل: متوفر / كمية محدودة / غير متوفر.
- منع إضافة الموديل غير المتوفر إلى السلة.
- سلة أكثر واقعية تعرض عدد السيري والقطع وإجمالي كل سطر.
- Checkout يحتوي مراجعة كاملة للطلب قبل الإرسال.
- فاتورة بعد تسجيل الطلب كما في النسخ السابقة.
- صفحة المنتج تعرض حالة التوفر ومسار تنقل ومزايا الطلب.
- إدارة حالة التوفر من صفحة إضافة/تعديل المنتج.
- تصدير واستيراد حالة التوفر في Excel/CSV.
- Service Worker جديد باسم V36 لمنع خلط الملفات القديمة.

## النشر
ارفع محتويات هذا المجلد كاملة مكان النسخة السابقة، ثم انشر `firestore.rules` الموجودة مع المشروع إذا كانت قواعد Firebase لم تطبق بعد.

## دخول الإدارة
لا يوجد زر إدارة ظاهر للعملاء. افتح رابط المتجر مع `?manage=1` ثم سجل الدخول بحساب الإدارة المصرح به.
