# Jood Kids Professional Web V35 Premium

نسخة متجر ويب احترافية ومتجاوبة مع الموبايل، مركزة على السرعة وسهولة البيع والإدارة بدون ازدحام.

## دخول الإدارة الخاص
لا يوجد أي زر أو رابط للإدارة في واجهة العملاء.
للدخول كمسؤول افتح رابط المتجر نفسه مع `?manage=1` ثم سجل الدخول بحساب Firebase المصرح به.

الحماية الفعلية تعتمد على Firebase Authentication وقواعد Firestore المرفقة، وليس على إخفاء الرابط.

## أهم تطويرات V35
- بحث ذكي بالموديل أو الاسم مع صورة وسعر ومقاس واقتراحات فورية.
- شريط تنقل سفلي سريع للموبايل مع الإبقاء على قائمة الثلاث شرطات.
- Dashboard إدارة أقوى: المنتجات، الظاهر، المخفي، العروض، الطلبات، طلبات اليوم وإجمالي الطلبات.
- صفحة مستقلة لإدارة العروض المخفضة.
- نسخ بيانات موديل لإنشاء موديل مشابه بسرعة.
- منع تكرار رقم الموديل وإرشاد المسؤول إلى المنتج الموجود بدل إنشاء نسخة مكررة.
- صفحة منتج محسنة للموبايل مع شريط إضافة ثابت والسحب بين الصور.
- إخفاء متابعة الطلبية تلقائيًا طالما التتبع العام غير مفعل.
- استمرار إصلاحات الحذف والتحقق من Firestore والحذف الجماعي بالدفعات.
- Cache V35 لمنع خلط ملفات النسخ القديمة والجديدة.

## العروض
أي منتج يحتوي `discountPercent` أكبر من صفر يظهر تلقائيًا في قسم العروض وفي صفحة إدارة العروض.

## النشر
ارفع محتويات هذا المجلد كما هي إلى GitHub Pages، وطبّق `firestore.rules` على مشروع Firebase.
