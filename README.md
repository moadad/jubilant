# Jood Kids Professional Web V33

نسخة متجر ويب احترافية ومتجاوبة مع الموبايل.

## دخول الإدارة الخاص
لا يوجد أي زر أو رابط للإدارة في واجهة العملاء.
للدخول كمسؤول افتح الموقع مع `?manage=1` ثم سجل الدخول بحساب Firebase المصرح به.
مثال محلي: `index.html?manage=1`

الحماية الفعلية تعتمد على Firebase Authentication وقواعد Firestore المرفقة، وليس على إخفاء الرابط فقط.

## العروض
أي منتج يحتوي `discountPercent` أكبر من صفر يظهر تلقائيًا في قسم العروض، ويظهر السعر بعد الخصم بوضوح.

## النشر
ارفع محتويات هذا المجلد كما هي إلى GitHub Pages، وطبّق `firestore.rules` على مشروع Firebase.
